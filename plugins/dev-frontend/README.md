# dev-frontend (plugin)

The plugin itself. For installation and configuration, see the [repository README](../../README.md). For usage, see the [Guide](GUIDE.md).

```
commands/                 /dev-frontend:* commands
skills/fe-standards/      shared rules: config, output language, developer notes,
                          branches, Definition of Ready/Done, templates, platform standards
config/                   example configuration
```

To change a rule (a branch pattern, a Definition of Done criterion, a platform convention), edit the matching file in `skills/fe-standards/references/`. Every command follows it.
